## 🚀 Projetos em Destaque

### 👾 1. [PRY2K.com.br](https://pry2k.com.br) — Plataforma Web Nostálgica Y2K com Inteligência Artificial
Projeto conceitual inovador que resgata a estética visual dos **anos 2000 (Y2K)** integrada com a tecnologia moderna de **LLMs (Inteligência Artificial Generativa)**.
- **Destaques**: Interface retro-futurista com micro-animações, consumo dinâmico de modelos de linguagem para geração interativa de conteúdos e experiência imersiva com suporte multi-dispositivo.
- **Tech**: C#, ASP.NET Core, APIs de LLM/AI, JavaScript, CSS3 Retro-Glassmorphic.

### 💼 2. [PortalJohn](https://github.com/johnmarl0n/PortalJohn) — Portal Pessoal Integrado, CRM & Strava Analytics
Plataforma web integrada que funciona como central de gestão comercial, análise de treinos e acervo bibliográfico.
- **Módulo Strava Analytics**: Worker em segundo plano (HostService) que se conecta à API do Strava via OAuth2 (auto-refresh de tokens) a cada 4h para ingestão de atividades esportivas. Vitrine pública com letreiro em tempo real e gráficos ApexCharts.
- **Módulo CRM Comercial**: Simulador de proposta comercial por hora técnica, ativação de contrato em 1-clique, pitch automático e cobrança automatizada via WhatsApp.
- **Redesign Biblioteca UI/UX**: Modal Centralizado estilo *Netflix/Apple Books* (840px em 2 colunas), busca universal instantânea com debounce e SQL `OR`, chips de filtros ativos e banner de métricas de leitura com progresso visual.
- **Tech**: .NET 8, ASP.NET Core MVC, ADO.NET, Identity (RBAC), CSS Vanilla Glassmorphism, SweetAlert2.

### 🩺 3. [Praxys Consultoria Psicológica](https://praxysconsultoria.com.br) — Plataforma B2B Corporativa (NR-1)
Plataforma B2B em **Clean Architecture** desenvolvida para consultoria de psicologia corporativa voltada para conformidade da NR-1.
- **Destaques**: Prontuário eletrônico criptografado, aplicação automatizada de inventários psicológicos (*PHQ-9, GAD-7*), gestão de CRM/Financeiro dual (B2B + B2C) e blog integrado otimizado para SEO local.
- **Tech**: .NET 9, Blazor, PostgreSQL, ASP.NET Core, RBAC Granular.

### 📱 4. ConsultorApp & Jacsys Core Server — Portal Corporativo Mobile & Motor de Integração
Central de dados corporativa para governança comercial, integração logística e automação.
- **Destaques**: Motor de disparos de WhatsApp em lote assíncrono, telemetria de leitura via Webhooks, dashboard de BI com funil de conversão (Chart.js) e integrações de WMS (*Spark WMS*) e suporte logístico.
- **Tech**: C#, SQL Server (ADO.NET), Webhooks, REST APIs, Chart.js.
